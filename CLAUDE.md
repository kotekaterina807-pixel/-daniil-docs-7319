# DocuStudio — инструкция для Claude Code (читай первой)

Программа собирает YouTube-видео 12–15 минут из сценария: озвучка, кадры, монтаж, 2K. Работает на ПК Даниила (Windows). Ты (облачный Claude Code/чат) на ПК не работаешь: связь через GitHub.

## Два репозитория
- Код программы: `kotekaterina807-pixel/-daniil-docs-7319` (этот). Версия в `pipeline/config.py` (VERSION). Программа обновляется с него сама, если включён `auto_update`.
- Очередь и отчёты: приватный `docustudio-reports`. Перед записью всегда `git pull --rebase`.
  - `queue/` — команды программе. Файл `.txt` = новая сборка (ниша берётся из строки `#! НИША:`), `.json` = правка/пересборка:
    `{"project": "<папка проекта>", "times": ["мм:сс", ...], "full": false}` (`"times": []` — пересобрать как есть).
  - Режимы сборки: в сценарии строка `#! РЕЖИМ: пробник` — быстрая проба 1080p без итоговой проверки Claude (для оценки стиля). Без этой строки — основное видео 2K 60 кадров/с. Пробник в чистовик: `{"project": "<папка>", "times": [], "final": true}` — пересборка из кэша в 2K без новой озвучки и подбора кадров. `#! РЕЖИМ: полный` — с проверкой кадров Claude (дорого, только по просьбе).
  - `scripts/` — готовые сценарии (образцы формата: `fawcett_1925_de.txt`), `TOPICS.md` — какие темы уже сделаны (проверяй ДО выбора темы!).
  - `status/live.json`, `status/remote.json` — что сейчас делает программа (не пушить код во время сборки).
  - `reports/<дата>_<проект>/` — отчёт сборки: контактные листы `видео_NN.jpg`, `монтаж_кадры.json`, `журнал.txt`, `статистика.json`.
- Готовое `.mp4` остаётся на ПК в `output/`, в репозиторий не попадает.

## Структура кода
`pipeline/runner.py` — сборка (step_build), `render.py` — монтаж и переходы, `looks.py` — вид ниш (студия/полароид), `cards.py` — карточки, `visuals.py` — поиск кадров (Pixabay, Pexels, Wikimedia, Internet Archive), `extras.py` — подписи/хук, `qa.py` — проверка кадров через Claude, `preflight.py` — проверка сценария, `script_format.py` — формат сценария (описание тегов в HEADER).
Ниши: `niches/*.json` (id, lang, target_minutes, style, visual_rules, script_rules, grade, card_theme, settings{edit_style, photo_cap, shot_seconds...}). Каждая ниша имеет свой монтаж; ниши не смешиваются. Новая ниша = новый json + шаблон сценария.
- Новую нишу строй ТОЛЬКО по роликам-примерам, которые прислал Даниил (ритм, длина кадров, карточки, озвучка, цвет, структура сценария). Не копируй `mysteries.json` и стиль «тайн» как образец. Из прошлого берётся только то, что не зависит от ниши: механика хука, переходы, общие лимиты (фото, карты, карточки).
- Порядок: примеры → файл ниши + шаблон сценария → пробник (1080p) → Даниил смотрит → при одобрении `"final": true` (2K).

## Правила Даниила
- Видео 12–15 мин. Хук 5–20 с: первая фраза — сильнейший факт, вопрос видео в первые 15 с, первый кадр движущийся.
- Неподвижное фото ≤ 6 с, карта ≤ 12 с подряд, карточка ≤ 4,5 с, повторы клипов подряд запрещены.
- Для тем до 1985 года: основа — подлинные фото (archive) и старая хроника (хроника); stock не более 1 строки из 10 и только вне времени (лёд, туман, огонь, вода, бумага). Никаких дронов, дорог, городов, туристов, современной техники.
- Ниша «тайны» (mysteries) отложена, не использовать.
- Активные ниши (26.11.2026): `fears.json` (страхи, вид «тьма»: чёрный фон, кадр в светящейся рамке, кадры 7–14 с, `photo_max_sec` 12 — по примерам Даниила) и `eat.json` (еда RU: топ-список, ведущий `[ведущий]`, `[далее]`, `[штамп]`, пословные подписи `#! ПОДПИСИ:`). Шаблоны: `docustudio-reports/scripts/templates/`. Испанская `food.json` — старая, не трогать.
- Всегда сверяй тему с `TOPICS.md` и `reports/`, чтобы не делать повторы.
- Отвечай Даниилу по-русски, коротко, без эмодзи; в конце сообщения — какая модель нужна дальше (Sonnet — разговор, Opus — монтаж/код).

## Экономия лимитов
Правь по возможности `niches/*.json` и сценарии, а не код. Не читай огромные файлы целиком (runner.py > 2500 строк): используй grep и sed -n. Проверку кадров через Claude (`qa.py`) включай только по запросу (`"full": true`).

## Разбор примеров
Ролики-примеры весят много, в чат их не загрузить (лимит ~30 МБ). Даниил кладёт их в папку `samples/` рядом с программой (подпапка = канал). Команда в `queue/`: `samples_1.json` = `{"samples": true}`. Программа сама зальёт в `reports/samples_<дата>/<папка>_<ролик>/` контактные листы (кадр раз в 3 с), хук 0–30 с по секундам, `статистика.json` (склейки, длина кадров) и облегчённую копию `видео_NN.mp4` (360p со звуком, части по 4 мин). По копии разбирай текст (расшифровка), темп речи, музыку и переходы; `{"samples": true, "video": false}` — без копий. После разбора копии из репозитория отчётов удаляй.
