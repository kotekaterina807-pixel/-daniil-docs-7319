Положите сюда фоновые треки (mp3/wav/m4a). Программа берёт случайный трек на каждое видео.
Можно сделать подпапки mysteries и military — тогда для ниши берутся треки из её подпапки.

Бесплатная музыка без претензий по авторским правам: Фонотека YouTube (YouTube Studio > Фонотека).
Используйте только треки, на которые у вас есть права, иначе видео получит заявку Content ID.
