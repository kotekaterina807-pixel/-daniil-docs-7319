Звуки для видео (mp3/wav). Название файла задаёт, где звук звучит:
  typewriter...mp3 — стук печатной машинки, пока на экране печатается лист с цитатой
  whoosh...mp3 — короткий «вжух» перед началом новой главы
Можно положить несколько файлов каждого вида — программа берёт случайный.
Где взять бесплатно: YouTube Studio > Фонотека > Звуковые эффекты (поиск: typewriter, whoosh).
