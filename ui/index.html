Нужен выбор кадров

  1. Нажмите «Открыть листы» — откроется папка проекта с файлами кадры_лист_01.jpg, 02…
  2. Перетащите все листы в чат Claude и напишите: «выбери кадры».
  3. Claude ответит списком строк вида 12: 3 1. Скопируйте ответ целиком.
  4. Нажмите «Вставить ответ Claude» — сборка продолжится сама.

Добавить голос по ID

            
Если у вас уже есть ID голоса ElevenLabs (Voice ID) — вставьте его сюда.

            
1. Откройте библиотеку и найдите голос (фильтр Language — нужный язык, например German).
2. У голоса нажмите «Add to my voices».
3. Нажмите ⋯ → «Copy voice ID» и вставьте сюда.

Какой голос искать под документалки

            
В библиотеке включите Language: Russian и Use case: «Narrative & Story». Хорошо подходят спокойные низкие голоса со словами в описании: deep, calm, narrator, documentary, storyteller. Слушайте на русском фразой «Моя фраза» — пример с сайта часто на английском.

Claude Code — проверка кадров по подписке

          

            
Вход в Claude Code
Откроется окно Claude Code, уже с прокси программы. Выберите «Claude account with subscription», войдите в браузере, затем введите /exit. Делается один раз

            
          

          

            
          

          

          
Ключи хранятся только на этом компьютере, в файле config.json в папке программы. Не пересылайте этот файл.
