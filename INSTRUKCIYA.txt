DOCUSTUDIO — ДОКУМЕНТАЛЬНЫЕ ВИДЕО ДЛЯ YOUTUBE
=============================================

1. УСТАНОВКА (один раз)
-----------------------
1) Распакуйте архив в папку, например C:\VideoGen
2) Двойной клик по install.bat. Python программа поставит сама, если его нет.
   «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
3) Запуск — ярлык DocuStudio на рабочем столе (создаёт install.bat) или start.bat.


2. ОБНОВЛЕНИЕ
-------------
Кнопка «Обновить программу» внизу меню слева. Программа сама скачивает новую версию с GitHub,
ставит её и перезапускается. Ключи, проекты, футажи и музыка не трогаются.
При каждом запуске программа сама проверяет, есть ли новая версия.


3. КЛЮЧИ (Параметры → Сервисы и ключи)
-------------------------------------
  Ключ Lumean     — озвучка голосами ElevenLabs и Claude для проверки кадров. lumean.app → API → Ключи.
                    Права ключа: «Все права» (Разрешения → Все права), галочка AI включена.
  Ключ ElevenLabs — (необязательно) озвучка напрямую. elevenlabs.io → Developers → API Keys. Нужен платный тариф
                    (Starter и выше: коммерческая лицензия; бесплатный блокируется через VPN).
  Ключ Claude     — проверка кадров по смыслу. console.anthropic.com → API Keys.
                    Без него кадры выбираются через листы в чат с Claude.
  Ключ Pixabay    — видео и фото. pixabay.com/api/docs → после входа ключ на странице.
  Прокси только для программы — порт из VPN-приложения (см. раздел 6). Пусто — обычное подключение.

Ключи хранятся только в config.json в папке программы. Никому его не отправляйте, в чат тоже.
«Проверить подключения» — проверяет прокси, ElevenLabs (остаток символов), Claude, Pixabay, FFmpeg.


4. ГОЛОСА (вкладка «Голоса»)
----------------------------
  1) «Открыть библиотеку голосов» → найдите голос (Language: Russian, Use case: Narrative & Story).
  2) У голоса «Add to my voices», затем ⋯ → «Copy voice ID».
  3) Вставьте ID в программу → «Добавить». Или «Загрузить все мои голоса».
  4) ▶ — пример с сайта, «Моя фраза» — ваш текст этим голосом. «Выбрать» — голос для видео.
  Скорость по умолчанию 0.9 (спокойный темп), стабильность 0.45.


5. ВИДЕО
--------
  Сценарий пишет Claude в чате и присылает файлом .txt.
  Главная → перетащите файл в рамку «Новое видео» → «Собрать видео».
  Прогресс, оставшееся время и этапы — на главной. Плашка сборки слева внизу ведёт туда же.
  Готовые видео — во вкладке «Проекты»: смотреть, описание для YouTube, пересобрать.

  Формат сценария:
    Абзац текста, под ним строки кадров — по одной на предложение, по порядку:
      [stock] запрос   — видео (запрос на английском: что видно в кадре)
      [archive] запрос — архивное фото (Wikimedia)
      [photo] запрос   — фото, если видео такого не бывает
    [человек] James Ducat | Джеймс Дукат — фото человека; справа — подпись на экране
    [надпись] Главное | пояснение — всплывающая подпись
    [переход] обычный / спокойный / эффектный


6. VPN ТОЛЬКО ДЛЯ ПРОГРАММЫ
---------------------------
  Чтобы YouTube и остальные программы работали как раньше, а VPN — только у DocuStudio:
  1) В VPN-приложении выключите режим «VPN / TUN / Системный прокси» — оставьте только подключение
     к серверу (режим «Прокси»). Приложение покажет локальный порт, например 10808 (SOCKS) или 10809 (HTTP).
  2) В DocuStudio: Параметры → Сервисы и ключи → «Прокси только для программы» → 127.0.0.1:10808
  3) «Проверить подключения» → строка «Прокси программы» покажет страну выхода.


7. ЧТО В ПАПКЕ ПРОЕКТА
----------------------
  <название>.mp4     — видео 1920x1080, 30 к/с, звук под YouTube (-14 LUFS)
  subtitles.srt      — субтитры (YouTube Studio → Субтитры → Загрузить файл)
  description.txt    — описание, таймкоды, использованные материалы, теги
  thumbnail_1..3.jpg — обложки 1280x720
  Список «Использованные материалы» в описании не удаляйте — часть фото требует указания автора.


8. МУЗЫКА
---------
  Положите mp3 в папку music (или music\mysteries, music\ocean… — для своей ниши).
  Трек выбирается случайно, громкость — во вкладке «Музыка».


ПРОВЕРКА КАДРОВ ЧЕРЕЗ CLAUDE CODE (по подписке Claude, без оплаты API)
1. Откройте PowerShell (Пуск → PowerShell) и выполните:
   irm https://claude.ai/install.ps1 | iex
2. Закройте и снова откройте PowerShell, введите: claude
   Выполните /login и войдите аккаунтом Claude с подпиской (Pro или Max). Потом /exit.
3. В программе: Параметры → Монтаж → «Кто проверяет кадры» → «Claude Code — по подписке».
4. Параметры → Сервисы и ключи → «Проверить подключения» — строка «Claude Code» должна быть зелёной.
Если VPN настроен только на отдельные программы — добавьте в него и DocuStudio.exe, и claude.exe
(%USERPROFILE%\.local\bin\claude.exe): Claude Code ходит в интернет сам.
