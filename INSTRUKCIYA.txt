ГЕНЕРАТОР ДОКУМЕНТАЛЬНЫХ ВИДЕО ДЛЯ YOUTUBE
===========================================

1. УСТАНОВКА (один раз)
-----------------------
1) Распакуйте архив в папку без русских букв в пути, например C:\VideoGen
2) Двойной клик по install.bat. Если Python не установлен, программа поставит его сама.
   Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
3) Дождитесь надписи «Готово».
4) Запуск программы: двойной клик по start.bat


2. КЛЮЧИ (вкладка «Настройки и ключи»)
-------------------------------------
Основной вариант — Yandex Cloud: работает из России, оплата картой РФ.
Один аккаунт даёт всё: сценарий (Alice AI LLM), проверку кадров (Qwen) и озвучку (SpeechKit).

А) Регистрация и оплата
  1) Откройте console.yandex.cloud и войдите через Яндекс ID.
  2) Создайте платёжный аккаунт (физлицо, карта РФ) и пополните баланс.
  3) Каталог «default» создаётся автоматически. Откройте его и скопируйте ID каталога
     (строка вида b1g...) — это поле «ID каталога Yandex Cloud» в программе.

Б) Сервисный аккаунт (от его имени программа обращается к нейросетям)
  1) В каталоге откройте сервис Identity and Access Management → Сервисные аккаунты → Создать.
  2) Имя любое, например videogen.
  3) Роли (кнопка «Добавить роль»):
       ai.languageModels.user   — сценарий и проверка кадров
       ai.speechkit-tts.user    — озвучка
  4) Создать.

В) API-ключ
  1) Откройте созданный сервисный аккаунт → «Создать новый ключ» → «Создать API-ключ».
  2) Область действия: yc.ai.foundationModels.execute
     (если в списке есть, добавьте также yc.ai.languageModels.execute и yc.ai.speechkitTts.execute).
  3) Создать. Скопируйте СЕКРЕТНЫЙ ключ сразу: после закрытия окна его не показать повторно.
  4) Вставьте его в поле «API-ключ Yandex Cloud».

Г) Pixabay (бесплатные видео, обязательно)
  1) pixabay.com → «Присоединиться» / Join → регистрация (почта или Google), подтвердить почту.
  2) Открыть pixabay.com/api/docs — после входа ключ показан прямо на странице
     (в разделе Parameters, строка key, подсвечен зелёным). Скопировать.
  3) Вставить в поле «Ключ Pixabay».
  Pexels: выдача новых ключей приостановлена. Если ключ Pexels уже есть — его можно вставить тоже.

Нажмите «Сохранить». Ключи хранятся только в файле config.json рядом с программой. Никому его не отправляйте.

Языки озвучки: Yandex озвучивает русский, английский и немецкий.
Для французского и испанского программа сама переключается на бесплатную озвучку Edge.

Если программа пишет «ключ не подходит или нет прав (401/403)» — проверьте ID каталога,
роли сервисного аккаунта и область действия ключа.


ЗАПУСК И ОБНОВЛЕНИЕ (версия 3.0 и новее)
  Запуск — ярлык DocuStudio на рабочем столе (его создаёт install.bat) или start.bat.
  Окно программы открывается отдельным приложением (через встроенный в Windows Edge).
  Обновление: Параметры → Обновления → «Выбрать архив…» → выберите присланный video_generator.zip.
  Программа сама заменит свои файлы, ключи/проекты/футажи/музыку не тронет, и перезапустится.
  Можно просто перетащить .zip в окно программы.
  Если новое окно не открывается — start_classic.bat запускает старый интерфейс.


3. СОЗДАНИЕ ВИДЕО
-----------------
СЦЕНАРИЙ ПИШЕТ CLAUDE В ЧАТЕ
  1) Напишите в чате: «сценарий: <тема>, <сколько минут>».
  2) Claude пришлёт файл .txt — сохраните его куда угодно.
  3) В программе выберите нишу и нажмите «▶ Видео из сценария…», выберите этот файл.
  4) Программа создаст проект в папке output и сама соберёт видео.
  Язык видео берётся из строки «#! ЯЗЫК:» в файле.

ФОРМАТ СЦЕНАРИЯ (если захотите править файл)
  Абзац текста, под ним строки кадров — по одной на каждое предложение, по порядку:
    [stock] запрос   — ВИДЕО Pixabay (основной вид кадра), запрос на английском: что видно в кадре
    [archive] запрос — архивное фото Wikimedia (реальные места, документы)
    [photo] запрос   — фото, только если видео такого не бывает
  [человек] James Ducat | Джеймс Дукат — фото человека (Википедия/Wikimedia, только свободные);
      справа от черты — как подписать на экране. Если свободного фото нет — будет подпись с именем.
  [надпись] Главное | пояснение — всплывающая подпись (не чаще раза в 45 секунд)
  Каждая строка кадров звучит вместе со своим предложением. Под одну строку программа берёт
  несколько разных роликов, кадр меняется примерно каждые 2 секунды (~90 кадров на 3 минуты).
  Переходы — только короткий плавный наплыв.

ГОЛОС ДИКТОРА
  «Настройки» → «▶ Прослушать все голоса»: программа озвучит одну фразу всеми голосами Yandex
  и откроет папку voice_samples. Послушайте, выберите голос в списке «Голос диктора», «Сохранить».

ПРОВЕРКА ПЕРЕД РАБОТОЙ
  Вкладка «Настройки и ключи» → «✔ Проверить всё»: программа проверит озвучку Yandex,
  проверку кадров, Pixabay, Wikimedia, FFmpeg, видеокарту и место на диске,
  и для каждой проблемы подскажет, что исправить.


СВОЯ БИБЛИОТЕКА ФУТАЖЕЙ (необязательно)
  Кнопка «📁 Мои футажи» открывает папку footage — туда можно положить свои ролики,
  программа будет подбирать их по смыслу вместе с Pixabay. Подробности в footage\README.txt.
  Если Pixabay или Wikimedia недоступны с компьютера, программа напишет об этом один раз
  и продолжит без них.


4. ЧТО ПОЛУЧАЕТСЯ В ПАПКЕ ПРОЕКТА
---------------------------------
  <название>.mp4     — готовое видео 1920x1080, 30 к/с, звук нормализован под YouTube (-14 LUFS)
  subtitles.srt      — субтитры: YouTube Studio → Субтитры → Загрузить файл
  description.txt    — описание, таймкоды глав, список использованных материалов, варианты названия, теги
  thumbnail_1..3.jpg — три варианта обложки 1280x720
  media\             — скачанные фото и видео

Список «Использованные материалы» в описании не удаляйте: часть архивных фото с Wikimedia
распространяется по лицензии CC BY / CC BY-SA, она требует указания автора.


5. МУЗЫКА
---------
Положите mp3 в папку music (или в подпапки music\mysteries и music\military).
Громкость музыки автоматически приглушается, когда говорит диктор.
Берите треки только с правами на использование, например из Фонотеки YouTube Studio.


6. СВОЯ НИША
------------
Скопируйте файл из папки niches, переименуйте и поменяйте:
  "id"                — латиницей, имя подпапки для музыки
  "name"              — название в списке
  "style"             — тон и подача рассказа
  "visual_hint"       — какие кадры подбирать
  "tts_instructions"  — как читать диктору (работает для озвучки openai)
  "grade"             — цветокоррекция ffmpeg
  "accent"            — цвет акцентов на обложке и карточках [R, G, B]
  "fallback_queries"  — запасные запросы для поиска кадров (на английском)
После перезапуска программы ниша появится в списке.


7. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
--------------------------
Ошибки пишутся в окно программы и в файл error_log.txt. Пришлите его текст — исправлю.
